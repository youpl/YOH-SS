## ANNEXE TOOLS
	* Pack SysInternals Complet
		* Lien : https://download.sysinternals.com/files/SysinternalsSuite.zip
		* Fonctionnalité : Pack contenant tous les outils SysInternals (portables, signés Microsoft)
		* Utilité en Forensic : Permet d'avoir tous les outils d'analyse système en un seul téléchargement
		* Type de cheat/bypass recherché : Tous types (analyse complète du système)

	# Analyse Processus & Mémoire
		* Process Hacker 2
			* Lien : https://sourceforge.net/projects/processhacker/files/processhacker2/processhacker-2.39-setup.exe/download
			* Fonctionnalité : Gestionnaire de tâches avancé avec analyse mémoire, handles, threads, modules
			* Utilité en Forensic :
				→ Identifier processus cachés ou injectés
				→ Analyser la mémoire d'un processus (dumps, strings)
				→ Lister les DLLs chargées et handles ouverts
				→ Détecter les hooks et injections
			* Type de cheat/bypass recherché :
				→ Cheats injectés dans javaw.exe
				→ Loaders résidant en mémoire
				→ Hooks clavier/souris (autoclickers)
				→ DLLs malveillantes chargées
				→ → Processus déguisés (ex: svchost.exe renommé)
				
		* Process Hacker 3 (System Informer)
			* Lien : https://github.com/winsiderss/si-builds/releases/download/3.0.5553/systeminformer-3.0.5553-setup.exe
			* Fonctionnalité : Version modernisée de Process Hacker avec interface améliorée et nouvelles fonctionnalités
			* Utilité en Forensic :
				→ Analyse mémoire plus performante
				→ Détection de code injecté
				→ Meilleure visualisation des threads et handles
				→ Support Windows 11
			* Type de cheat/bypass recherché :
				→ Injections mémoire fileless
				→ Cheats Java externes (via strings en mémoire)
				→ Code chargé dynamiquement
				→ Bypasses anti-debug


		* Process Explorer (SysInternals)
			* Lien : https://live.sysinternals.com/procexp.exe (32-bit) / https://live.sysinternals.com/procexp64.exe (64-bit)
			* Fonctionnalité : Gestionnaire de processus avancé avec arbre hiérarchique et vérification de signatures
			* Utilité en Forensic :
				→ Voir les relations parent-enfant entre processus
				→ Vérifier les signatures numériques (fichiers non signés = suspects)
				→ Identifier les processus consommant des ressources
				→ Analyser les DLLs et handles
			* Type de cheat/bypass recherché :
				→ Loaders lançant des processus enfants
				→ Exécutables non signés
				→ Processus masqués sous des noms légitimes
				→ Injections de DLLs


		*  Process Monitor (Procmon)
			* Lien : https://live.sysinternals.com/Procmon.exe (32-bit) / https://live.sysinternals.com/Procmon64.exe (64-bit)
			* Fonctionnalité : Moniteur temps réel des activités fichiers, registre, réseau et processus
			* Utilité en Forensic :
				→ Capturer toutes les actions d'un processus suspect
				→ Voir les fichiers créés/modifiés/supprimés
				→ Détecter les modifications de registre
				→ Tracer les connexions réseau
			* Type de cheat/bypass recherché :
				→ Loaders téléchargeant des payloads
				→ Modifications de registre (persistence)
				→ Création de fichiers temporaires (.dll, .exe)
				→ Communications C2 (Command & Control)
				→ Bypass UAC

			* Fonctionnalité : Extrait les chaînes de caractères ASCII/Unicode d'un fichier binaire

		* PEStudio
			* Lien : https://www.winitor.com/download
			* Fonctionnalité : Analyse statique de fichiers PE (Portable Executable) avec détection d'anomalies

				→ Identifier les sections suspectes (haute entropie = crypté)

				→ Détecter les packers/crypters (UPX, Themida)

	# Analyse Forensic Windows
		* fsutil USN Journal (Windows natif)
			* Lien : Outil intégré Windows (aucun téléchargement nécessaire)
			* Fonctionnalité : Interroge et lit le Change Journal NTFS d'un volume
			* Utilité en Forensic :
				→ Détecter les créations, suppressions et renommages de fichiers
				→ Conserver un export source avec `usn_all.csv`
				→ Repérer des traces de nettoyage ou de dissimulation
				→ Identifier les fichiers .jar/.exe/.bat/.dll manipulés récemment
			* Type de cheat/bypass recherché :
				→ Loaders créés puis supprimés
				→ Cheats Java externes (.jar)
				→ Scripts de lancement ou nettoyage (.bat/.ps1)
				→ DLLs renommées ou injectées puis supprimées
				→ Tentatives anti-forensic via suppression de traces
			* Commandes utiles :
				→ fsutil usn queryjournal C:
				→ fsutil usn readjournal C: csv > usn_all.csv
				→ fsutil hardlink list C:\chemin\fichier.exe

		* JournalTrace
			* Lien : outil à utiliser depuis votre pack / source habituelle
			* Fonctionnalité : Lecture graphique du journal NTFS / USN avec reconstruction de champs utiles
			* Utilité en Forensic :
				→ Filtrer rapidement sur Reason = Hard Link / Hard link change
				→ Voir Name, Directory, Current file et File Identification
				→ Retrouver un hardlink supprimé après selfdestruct
				→ Associer un alias supprimé à un fichier courant
			* Type de cheat/bypass recherché :
				→ javaw.security lié à un fichier .pf déguisé
				→ BLUE.pf / fichier payload sans logs classiques
				→ Hardlink dans dossiers Java / PrismLauncher / Temp
				→ Bypass qui supprime l'alias avant la vérification
			* À relever :
				→ Name
				→ Directory
				→ Current file
				→ Reason
				→ Date
				→ File Identification

		* AmcacheParser
			* Lien : https://download.ericzimmermanstools.com/net9/AmcacheParser.zip
			* Fonctionnalité : Parse la ruche Amcache.hve et génère des CSV exploitables
			* Utilité en Forensic :
				→ Retrouver des exécutables supprimés ou déplacés
				→ Obtenir chemins, noms, SHA1, éditeurs et timestamps
				→ Identifier un loader même si son fichier n'est plus présent
				→ Corréler un nom USN / Prefetch avec un chemin et un hash
			* Type de cheat/bypass recherché :
				→ Loaders portables exécutés puis supprimés
				→ Autoclickers .exe
				→ DLLs suspectes inventoriées
				→ Exécutables dans AppData / Temp / Downloads / Desktop / OneDrive
				→ Fichiers renommés pour dissimulation
			* Commande utile :
				→ AmcacheParser.exe -f C:\Windows\AppCompat\Programs\Amcache.hve --csv C:\Sortie

		* Registry Explorer
			* Lien : https://download.ericzimmermanstools.com/net9/RegistryExplorer.zip
			* Fonctionnalité : Visualiseur graphique de ruches registre Windows
			* Utilité en Forensic :
				→ Ouvrir Amcache.hve directement
				→ Ouvrir la ruche SYSTEM pour BAM/DAM
				→ Ouvrir NTUSER.DAT / UsrClass.dat pour l'activité utilisateur
				→ Rechercher un nom, chemin ou hash précis
				→ Vérifier manuellement une entrée Amcache
				→ Explorer une ruche sans la charger dans le registre système
			* Type de cheat/bypass recherché :
				→ Confirmation d'un loader repéré par AmcacheParser
				→ Vérification d'un chemin BAM associé à un utilisateur
				→ Vérification de RunMRU / RecentDocs / UserAssist
				→ Vérification manuelle d'un chemin suspect
				→ Recherche de traces dans une ruche copiée
			* Usage utile :
				→ File -> Load Hive -> Amcache.hve / SYSTEM / NTUSER.DAT / UsrClass.dat
